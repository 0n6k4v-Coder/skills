# Methodology

Workflow Insights is an observation → hypothesis → intervention → evaluation loop.

## Operating sequence

1. **Scope** the corpus before interpretation.
2. **Measure** deterministic facts.
3. **Sample** representative sessions.
4. **Classify** individual sessions.
5. **Aggregate** repeated observations.
6. **Challenge** conclusions with counterevidence.
7. **Recommend** the smallest effective intervention.
8. **Experiment** with explicit success criteria.
9. **Compare** against a baseline.
10. **Keep or revert** the intervention.

## Evidence hierarchy

Use this ordering when resolving conflicts:

1. Raw session evidence
2. Deterministic metrics
3. Repeated session observations
4. Model-generated classifications
5. Cross-session hypotheses
6. Recommendations

Lower levels cannot silently override higher levels.

## Recommendation discipline

A recommendation must be:

- grounded in observed evidence
- scoped to the affected context
- actionable
- minimal
- testable

Avoid personality claims. Describe behaviors and conditions instead.

## Human control

This Skill is user-invoked by design. Analysis can propose changes, but it must not silently mutate CLAUDE.md, Skills, hooks, MCP configuration, or other persistent workflow artifacts.

## Quality bar

A shorter report with three well-supported findings is better than a long report with ten speculative insights.
